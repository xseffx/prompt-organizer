# Prompt Organizer

A small command-line tool for saving, organizing, and searching AI prompts.

## Features

- Save prompts locally
- Organize prompts by category
- List saved prompts
- Search prompts
- Display individual prompts
- Stores data in a simple JSON file
- No external dependencies

## Requirements

Python 3.8 or newer.

## Usage

Add a prompt:

```bash
python prompt_organizer.py add "Coding Helper" coding "Explain this Python code"
